## Status

This integrates ONS half-hourly `*_tm` constrained-off rows using `MW * 0.5 h`. The public ONS dictionary defines `val_geracaolimitada` as limited generation, not lost energy, so this report separates:

- `frustrated_generation_twh`: `max(val_geracaoreferenciafinal - val_geracao, 0) * 0.5 h`, where ONS publishes `val_geracaoreferenciafinal`.
- `limited_setpoint_twh`: integral of `val_geracaolimitada`, retained only as a diagnostic/setpoint quantity.

Use the frustrated-generation column for annual Brazil examples. Do not use the limited-setpoint integral as curtailed energy.

## DARI Use

Brazil can be used as the first measured constrained-off annual-floor slice with state/fuel labels. The repo loader has been reconciled to this annual-energy definition: it uses `val_geracaoreferenciafinal - val_geracao` and tags ONS points with `intervalHours = 0.5`. The annual floor is emitted separately in `data/source-verified-floor/2025.csv`; the dashboard's rolling 30-day Brazil profile remains a live operational view, not the annual floor file.
