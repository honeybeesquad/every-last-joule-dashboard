# CEA Monthly Renewable Curtailment Source Note

Date: 2026-05-07

## Bottom Line

CEA monthly renewable generation reports are now a high-value official source path for Indian state-level curtailment anchors. They include a table titled `RE Curtailment Data as available from SLDCs`, with monthly state-level curtailment in MU and source attribution to state SLDC pages or SLDC-furnished information.

This may be more immediately useful than scraping dead state SLDC forms because it gives official monthly curtailment values where CEA published them. It is an official monthly anchor source, not an event-level source.

The current source-locked extraction artifact is `docs/research/2026-05-07-cea-monthly-curtailment.md`, with normalized rows in `docs/research/2026-05-07-cea-monthly-curtailment.csv`. It is generated by `node scripts/research/cea-monthly-curtailment-extract.mjs`.

## Source Meaning

- Unit: MU, equivalent to GWh.
- Conversion: `1 MU = 0.001 TWh`.
- Provenance: CEA table explicitly says values are as available on SLDC websites or furnished by SLDCs.
- Scope: monthly state-level curtailment, not interval/event-level rows.

## Methodological Use

Use CEA tables as official monthly anchors where numeric values are present. Do not infer zeros from blanks or dashes. Preserve each row's source text because some values come from state websites while others are furnished by SLDCs through non-public channels.

Do not substitute newer `RE Deviation Data for ISGS` tables for curtailment tables. Deviation is schedule-vs-actual settlement/operation data and is not a curtailed-energy measure unless the source explicitly labels a field as curtailment, backing down, or constrained-off renewable energy.
