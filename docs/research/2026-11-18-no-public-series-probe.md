# Probe: grids the roster marked "no public series" (2026-11-18)

**Question.** Do the operators behind ten roster regions marked as having no public series, plus the Faroe Islands, publish a machine-readable generation series? Does any of them publish curtailment or spill?

**Method.** Endpoints were located by reading the URL constants in Electricity Maps' open-source parsers (`electricitymaps-contrib`, AGPL). No code from that repo was copied or adapted; every finding below comes from requesting the endpoint directly and reading the response. Requests ran from a Claude Code cloud container (a datacentre IP, as GitHub Actions and Vercel are) on 2026-11-18 between 09:40 and 10:40 UTC, with plain HTTP clients and no browser User-Agent. Where a host answered 403, it was not retried with a spoofed client.

**Answer.** Five operators publish a usable generation time series: AMM (Guatemala), CNDC (Nicaragua), UT (El Salvador), Yukon Energy and CNDC (Bolivia). Three publish only a snapshot or no generation at all (SaskPower, NS Power, NB Power). Three refused this IP (ICE, SEV, the PEI government API). **None publishes curtailment, spill or a restriction series** in the payloads probed.

## Notes

- **Reachable here ≈ reachable from the build.** The dashboard's loaders run on GitHub Actions and Vercel, which are datacentre IPs like this container. A source that answered here is likely to answer there; the three 403s are likely to 403 there too. ICE, SEV and PEI should be retried from `abed` (home IP) before being called dark; if they answer there, they are relay candidates, not live loaders.
- **Snapshots are not series.** SaskPower and NS Power each publish one number per fuel at a time. Collecting them would need a snapshot lake (as Puerto Rico does) before a diurnal profile exists. They are not wired in this pass.
- **Saskatchewan's existing loader is decorative.** `src/data/saskatchewan.json.ts` fetches `saskpower.com`, then always throws and serves a typical wind shape anchored at ~0.15 TWh/yr. That is the "live probe that always falls through" pattern `CLAUDE.md` rule 3 warns about. The anchor has no citation. Left unchanged here; flagged as a follow-up.
- **Nicaragua carries today only.** A build early in the Nicaraguan day sees a handful of hours. A loader must require a near-full day and otherwise fall back to its last-good snapshot.
- **El Salvador and Bolivia currently serve modelled waste** (`statics.json.ts`: 0.2 and 0.1 TWh/yr, IRENA-derived, no operator curtailment figure). Moving them to generation-only with unpublished waste removes 0.3 TWh/yr from the modelled total. That is a dataset-total change and needs the owner's sign-off.
- **Ember/OWID cross-check not done here.** No probe value was annualised or compared with national statistics in this note; loader PRs do that for their own region.
