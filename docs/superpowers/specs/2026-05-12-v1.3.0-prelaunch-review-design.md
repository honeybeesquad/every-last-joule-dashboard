## Phase 5 — Deep code review

Bounded but thorough. Run in this order:

1. **CI gates** — all three must be green:
   - `npx tsx scripts/ci/check-tier-coherence.ts`
   - `npx tsx scripts/ci/check-tally-golden.ts`
   - `npx tsx scripts/ci/check-source-provenance-coherence.ts`
2. **Tests** — `npm test` (target ~402+ tests passing)
3. **Build** — `npm run build` clean (no warnings; cache bust active)
4. **Dead-code hunt** — `grep -rn "TODO\|FIXME\|XXX" src/ scripts/` triaged; orphan loader/component search; check for unreferenced exports
5. **Performance scan** — bundle size delta vs prior tag; identify any new large dependencies; check for obvious render-hot-path inefficiencies in `mountGlobe`, `region-tooltip`, snapshot-loading paths (do not refactor `mountGlobe`; just flag if a clear bottleneck is found)
6. **Console-noise audit** — no stray `console.log` shipped in `src/`
7. **Type-check** — `npx tsc --noEmit` if applicable

Anything found is either fixed in this branch or recorded as a known-limitations entry. Nothing is hand-waved.
